# Release notes — Trilogicon reference node V2.0.0

**Tag:** `v2.0.0` (recommended)  
**Scope:** **Node hardening** on the **unchanged V1 transfer protocol** (accounts, signed transfers, blocks, linear chain, fee burn, shared genesis).

This release marks **closure of the V2 implementation line** for the reference Rust `node` crate: operational robustness, not new ledger rules. See [`docs/v2_checkpoint.md`](../v2_checkpoint.md) and [`docs/v2_freeze.md`](../v2_freeze.md).

---

## Highlights

- **Persistence:** V2 `chain.blocks` format (magic + CRC per frame) for new files; legacy length-prefixed files still load; fail-closed load with a **narrow** documented tail repair (1–3 bytes after last complete frame only).
- **Restart safety:** `genesis_bind.toml`, `.node.run.lock`, `pending_tx.tril` + `.pending_tx.lock`, deterministic replay.
- **Networking:** Session handshake (wire version + genesis commitment), ingress quotas, typed disconnects, defensive timeouts and caps ([`design_notes/v2_network_defense.md`](../design_notes/v2_network_defense.md), [`v2_wire_peer_sync.md`](../design_notes/v2_wire_peer_sync.md)).
- **Sync:** Linear catch-up only; bounded work per call (`SyncWorkBudget`); peer height advisory.
- **Mempool:** Local FIFO hygiene, seal candidate rules aligned with docs; no fork choice.
- **Operator UX:** Subsystem-tagged stderr (`[startup]`, `[peer]`, `[sync]`, etc.); README runbook updates.

---

## Not in this release

- Smart contracts, staking, governance, bridges, multi-asset protocol features.
- Fork choice, reorg, or longest-chain selection in the reference node.
- Production wallet UI or custody product.
- Guaranteed global DoS resistance or full partition safety—scope remains honest; see checkpoint **Honesty** section.

---

## Upgrade / operator notes

- **Same genesis** as V1 deployments; **disk layout** may add CRC framing for **new** chain files; legacy files unchanged.
- Review [`docs/design_notes/v2_persistence_restart.md`](../design_notes/v2_persistence_restart.md) for fail-closed recovery.
- **V2 is frozen** after this tag for protocol semantics; evolution is **V3+** with explicit specs ([`docs/v3_scope.md`](../v3_scope.md)).
