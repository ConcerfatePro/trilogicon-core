# Trilogicon v2.0.0

V2 hardens the reference node without changing V1 protocol semantics.

## Highlights

- Safer `chain.blocks` storage for new files: V2 magic + CRC.
- Fail-closed startup on corrupt or inconsistent local chain data.
- Genesis data-dir binding.
- Pending transaction drain/rewrite semantics.
- TCP handshake with wire version and genesis commitment.
- Bounded peer sessions and linear sync work.
- Local mempool capacity and cleanup.
- Clearer subsystem-prefixed stderr messages.

## Compatibility

- V1 block and transaction validity are unchanged.
- Legacy `chain.blocks` files still load.
- No fork choice, reorg execution, staking, rewards, or smart contracts.

## Verify

```bash
cd node
cargo fmt --check
cargo test
cargo clippy -- -D warnings
```
