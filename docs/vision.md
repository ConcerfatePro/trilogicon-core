# Vision

Trilogicon is a small Rust blockchain project focused on clarity over feature count.

Near-term work is about making the reference node understandable and hard to mis-run: deterministic state replay, explicit genesis handling, bounded peer behavior, and honest docs.

Longer-term V3 work explores branch representation, fork choice, reorg planning, and confirmation language. That work is not a claim of production security.

Non-goals remain important: no smart contracts, staking economy, governance token, bridge, or DeFi layer unless a future scope document deliberately opens that work.
