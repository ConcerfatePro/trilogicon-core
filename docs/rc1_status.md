# Trilogicon RC1 Status

Current release candidate: `v1.0.0-rc1`

## Meaning
Trilogicon V1 is feature-frozen.

## Current focus
- bug fixes
- testing
- documentation
- operator experience
- private technical validation

## Not the focus right now
- new features
- scope expansion
- major protocol redesign
- “making it look more advanced”

## Next objective
Use RC1 to find bugs, tighten docs, and confirm repeatable operation before any broader release stage.
